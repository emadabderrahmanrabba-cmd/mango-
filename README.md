# mango

A small utility library for working with fruit inventory data in JavaScript/TypeScript.

## Features

- Lightweight parsing of inventory CSV files
- Zero dependencies
- TypeScript types included

## Installation

```bash
npm install mango-
```

## Usage

```js
import { parseInventory } from 'mango-';

const data = parseInventory('./stock.csv');
console.log(data);
```
